# Theodia Prayer Lectionaries

A dedicated repository of downloadable lectionary schedules for the Theodia app.

| File | Contents |
|---|---|
| `RCL-Year-A.prayer.zip` | Revised Common Lectionary Year A (2025-26) readings |
| `RCL-Year-B.prayer.zip` | Revised Common Lectionary Year B (2026-27) readings |
| `RCL-Year-C.prayer.zip` | Revised Common Lectionary Year C (2027-28) readings |
| `Daily-Office-Year-Two-2025-26.prayer.zip` | Episcopal BCP 1979 Daily Office lectionary, Year Two (2025-26): psalms and lessons for each day |
| `Daily-Office-Year-One-2026-27.prayer.zip` | Episcopal BCP 1979 Daily Office lectionary, Year One (2026-27): psalms and lessons for each day |
| `Jewish-Weekly-Torah-5786.prayer.zip` | Standard Ashkenazi weekly Torah portion (parashah) lectionary with Haftarot for Jewish year 5786 (2025-2026) |
| `Jewish-Weekly-Torah-5787.prayer.zip` | Standard Ashkenazi weekly Torah portion (parashah) lectionary with Haftarot for Jewish year 5787 (2026-2027) |
| `One-Year-Daily-Bible-Reading-Plan.prayer.zip` | A canonical one-year daily Bible reading plan with Old Testament, New Testament, Psalm, and Proverb readings for each day |
| `Psalm-Of-Day-Proverbs-Of-Day.prayer.zip` | A simple daily lectionary with a Psalm and Proverbs chapter for each day of the year |
| `Presbyterian-Reformed-Lectionary-2026-27.prayer.zip` | Reformed Sunday lectionary with Old Testament, Psalm, Epistle, and Gospel readings for 2026-27, including Reformation Sunday |
| `Coptic-Lectionary-2026-27.prayer.zip` | Simplified Coptic Orthodox Sunday lectionary with Old Testament, Psalm, Epistle, and Gospel readings for 2026-27 |
| `Anabaptist-Lectionary-2026-27.prayer.zip` | Anabaptist / Mennonite discipleship lectionary emphasizing the Sermon on the Mount, peace, and reconciliation for 2026-27 |

## Source

Revised Common Lectionary scripture citations are from the Vanderbilt Divinity Library (https://lectionary.library.vanderbilt.edu).

Daily Office psalms and lessons are from the Episcopal Book of Common Prayer (1979), pp. 934-939 ("Concerning the Daily Office Lectionary"), in the JSON transcription at https://github.com/reubenlillie/daily-office.
